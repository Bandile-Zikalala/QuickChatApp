# QuickChatApp - PROG5121 POE Part 1

**Student:** Bandile Zikalala
**Module:** PROG5121 - Programming 1A

## Description
QuickChat Part 1 implements user registration and login with validation for username, password and cellphone number.

## Features
- checkUserName: validates username contains _ and <=5 chars (e.g. kyl_1)
- checkPasswordComplexity: validates 8+ chars, capital, number, special char (e.g. Ch&&sec@ke99!)
- checkCellPhoneNumber: validates +27 number (e.g. +27838568976)
- registerUser, loginUser, returnLoginStatus

## How to Run
1. Clone: git clone https://github.com/Bandile-Zikalala/QuickChatApp.git
2. Open in NetBeans
3. Run QuickChatApp.java
