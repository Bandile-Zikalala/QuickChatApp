## Description
QuickChat is a console-based chat application. Part 1 implements user registration and login with validation for username, password and cellphone number.

## Features Implemented (Part 1)
- checkUserName: validates username contains _ and <=5 chars (e.g. kyl_1)
- checkPasswordComplexity: validates 8+ chars, capital letter, number, special char (e.g. Ch&&sec@ke99!)
- checkCellPhoneNumber: validates SA number with +27 code (e.g. +27838568976)
- registerUser: returns registration status messages
- loginUser & returnLoginStatus: handles login

## How to Run
1. Clone repo: git clone https://github.com/Bandile-Zikalala/QuickChatApp.git
2. Open in NetBeans / IntelliJ
3. Run QuickChatApp.java
4. Follow prompts to register and login
